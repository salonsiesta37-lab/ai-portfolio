# かめいクリニック Web 予約システム

診療時間に合わせた予約枠を自動生成し、患者さんが入力した問診内容をクリニックのメールへ送る予約システムです。
サーバーを用意しなくても、このリポジトリを GitHub Pages に置くだけで動きます。

| ページ | ファイル | 用途 |
| --- | --- | --- |
| 予約フォーム | `index.html` | 患者さんが日時を選び、問診内容を入力して送信します |
| 予約一覧 | `admin.html` | 受付で予約枠の埋まり具合と予約リストを確認します |

公開後の URL（GitHub Pages の場合）

- 予約フォーム: `https://salonsiesta37-lab.github.io/ai-portfolio/clinic-booking/`
- 予約一覧: `https://salonsiesta37-lab.github.io/ai-portfolio/clinic-booking/admin.html`

---

## 1. できること

- **診療時間から予約枠を自動生成** — 曜日ごとの診療時間を設定すると、20 分刻みの枠を自動で並べます
- **初診は 20 分に 1 名** — 受付種別ごとに受入人数を設定できます（初診 1 名／再診 2 名が初期値）
- **休診日を自動で除外** — 休診曜日・祝日・臨時休診日は選べないように表示します
- **問診内容をメール送信** — 氏名・ふりがな・生年月日・連絡先・保険証・症状をクリニック宛に送ります
- **予約のリスト化** — 日付・状態・キーワードで絞り込み、CSV 出力・印刷ができます
- **枠ごとの空き状況ボード** — 受付で「何時が空いているか」を一目で確認できます

## 2. 最初に設定すること

編集するのは **`js/config.js` だけ**です。

### (1) クリニック情報とメールアドレス

```js
name:  'かめいクリニック',
tel:   '000-0000-0000',       // 実際の電話番号
email: 'yoyaku@example.com',  // 予約内容の送信先メールアドレス
```

### (2) 診療時間 ★必ず実際の時間に合わせてください

`schedule` の数字は曜日です（`0`=日 `1`=月 … `6`=土）。
**初期値は一般的な標榜時間を仮に置いたものです。かめいクリニックの実際の診療時間に必ず書き換えてください。**

```js
schedule: {
  0: [],                                                  // 日曜：休診
  1: [ { start: '09:00', end: '12:00', label: '午前' },
       { start: '15:00', end: '18:00', label: '午後' } ],  // 月曜
  4: [ { start: '09:00', end: '12:00', label: '午前' } ],  // 木曜：午後休診
  6: [ { start: '09:00', end: '13:00', label: '午前' } ],  // 土曜：午前のみ
},
```

休診にしたい曜日は `[]`（空の配列）にします。
お盆・年末年始などの臨時休診は `closedDates` に日付を追加してください。

```js
closedDates: ['2026-08-13', '2026-08-14', '2026-08-15'],
```

### (3) 予約枠の条件

| 設定項目 | 意味 | 初期値 |
| --- | --- | --- |
| `slotMinutes` | 予約枠の長さ（分） | `20` |
| `visitTypes[].capacity` | 同じ枠に受け入れる人数 | 初診 `1` ／ 再診 `2` |
| `newPatientCloseBeforeEndMin` | 初診の受付を診療終了の何分前で締め切るか | `0`（締め切らない） |
| `bookingWindowDays` | 何日先まで予約を受け付けるか | `30` |
| `minLeadMinutes` | 何分前まで当日予約を受け付けるか | `60` |

再診の予約を受け付けない場合は、`visitTypes` から再診の行を削除してください。

## 3. メールの送信方法を選ぶ

`js/config.js` の `sendMode` で切り替えます。

### 方式 A: `'mailto'`（初期設定・すぐ使えます）

患者さんが「予約する」を押すと、**患者さんのメールソフトが起動し、予約内容が入力された状態**でクリニック宛のメールが開きます。あとは送信ボタンを押すだけです。

- サーバーの用意が不要で、公開すればすぐ使えます
- 予約データは、患者さんのブラウザと受付端末それぞれにしか残りません
- そのため `admin.html` の一覧には「その端末で入力した予約」しか表示されません
- 空き状況もリアルタイムでは共有されません

> 動作確認や、電話予約が中心で Web からの予約が少ない場合に向いています。

### 方式 B: `'endpoint'`（実運用向け・おすすめ）

Google Apps Script を経由して、**送信ボタンを押した瞬間にクリニックへメールが届き、予約がスプレッドシートに貯まります**。空き状況もすべての患者さんで共有されます。

導入手順:

1. Google スプレッドシートを新規作成する
2. 「拡張機能 > Apps Script」を開き、`gas/Code.gs` の内容をすべて貼り付ける
3. `SETTINGS` の `clinicEmail`（通知先）と `token`（任意の合言葉）を書き換える
4. 「デプロイ > 新しいデプロイ > ウェブアプリ」を選び、
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**

   でデプロイし、表示された URL をコピーする
5. `js/config.js` を次のように変更する

```js
sendMode: 'endpoint',
endpoint: {
  url:   'https://script.google.com/macros/s/xxxxxxxx/exec',
  token: 'Code.gs の SETTINGS.token と同じ合言葉',
},
```

同じ枠に同時に申し込みが来ても、後から来た方には「この枠はちょうど埋まりました」と表示され、二重予約になりません。
患者さんがメールアドレスを入力した場合は、控えのメールも自動送信されます（`sendCopyToPatient` で切り替え）。

## 4. 受付での使い方（`admin.html`）

- **予約枠の状況** — 日付と種別を選ぶと、その日の枠が並びます。予約が入っている枠には患者名が表示されます
- **予約リスト** — 「本日」「今後 7 日」などで絞り込み、`来院済` `キャンセル` ボタンで状態を変更できます
- **CSV 出力** — 絞り込んだ内容をそのまま Excel で開ける形式で保存します
- **印刷** — 当日の一覧を紙で持ち歩けるように、操作ボタンなどを省いて印刷します
- **バックアップ** — 方式 A のときは、端末を替える前に必ず保存してください

受付用のパスコードをかける場合は `js/config.js` の `adminPasscode` に文字列を設定します。
ただしこれは画面をすぐ開けなくするための簡易的なものです。**院外から見られたくない情報を扱うため、`admin.html` は院内の端末でのみ開いてください。**

---

## 5. 個人情報の取り扱いについて

このシステムは患者さんの氏名・生年月日・連絡先・症状を扱います。運用前に次の点をご確認ください。

- 方式 A では、患者さんの入力内容は**患者さん自身のブラウザ**と送信されたメールにのみ残ります
- 方式 B では、予約データは**クリニックの Google アカウント**のスプレッドシートに保存されます。共有設定は必ず限定してください
- `admin.html` は検索エンジンに登録されないよう `noindex, nofollow` を設定していますが、URL を知っていれば誰でも開けます。パスコードの設定と、URL の取り扱いにご注意ください
- 予約フォームからクリニックへ送る内容は「診療の予約に必要な範囲」にとどめています。項目を増やす場合は、利用目的の掲示もあわせてご検討ください

## 6. ファイル構成

```
clinic-booking/
├── index.html          患者用 予約フォーム
├── admin.html          受付用 予約一覧
├── css/booking.css     2 ページ共通のスタイル
├── js/
│   ├── config.js       ★設定ファイル（ここだけ編集します）
│   ├── core.js         予約枠の生成・保存・入力チェック
│   ├── holidays.js     日本の祝日の計算（振替休日・国民の休日にも対応）
│   ├── booking.js      予約フォームの画面制御
│   └── admin.js        予約一覧の画面制御
├── gas/Code.gs         Google Apps Script（方式 B を使う場合）
└── README.md           このファイル
```

外部ライブラリは使用していません。通信先は Content-Security-Policy で Google Fonts と Apps Script のみに限定しています。
